## 3. 抽查的弹层

- **Settings 抽屉**：六项设置下拉（跨角色装备行为 / 小屏收缩侧栏 / 展开面板位置 / 遗器编辑器定位器 / Combo DMG 警告 / 新角色默认序）——`global.settings.update` 在册，其 gaps 点名的 RelicEquippingBehavior、NewCharacterRank 均实测在场。
- **Add New Relic 弹窗**：部位单选×6、套装/强化/星级下拉、主词条（未选部位时禁用、选后按星级强化自动算值）、Equipped by、4 条副词条各带低/中/高升级钮与预览标记、Cancel/Submit——与 `relics.upsert` 行 action/params 逐项一致。
- **页头语言下拉**（value="English"）：确认 `global.language.switch`（missing，MCP 固定 zh_CN）的网页入口存在。

## 4. 盘点发现与处置

1. **无未登记的页面级功能**：13 个页面 + 抽查弹层的全部可见控件都能映射到清单行或其 params/conditions 字段；未发现"浏览器可见但清单缺失"的整块功能。
2. 导航 "LeaderboardsNew" 实为 Leaderboards + NEW 徽章拼接，非未翻译键；徽章机制由 global.newFeature.badges 承载。
3. Get Started 侧栏按钮在无存档状态下点击未弹出抽屉（可能按存档状态条件渲染）——该行为差异不影响 `global.gettingStarted.loadSample` 行的登记（partial：示例存档可载入、入口不可发现），M4 实现时按实际条件补验收用例。
4. 动态渲染面（ag-grid 内部滚动条、portal 菜单）属呈现细节，无业务动作，不需要清单行；与 census 口径一致（源码 JSX 交互面全量入册）。
